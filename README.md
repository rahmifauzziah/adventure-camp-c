## Deskripsi Proyek

Adventure Camp merupakan aplikasi berbasis console yang dikembangkan menggunakan bahasa C. Program ini dirancang untuk mengelola proses penyewaan perlengkapan berkemah secara digital, mulai dari kalkulasi biaya otomatis berdasarkan jenis alat, kuantitas, durasi sewa, hingga penerapan potongan harga (diskon 10% untuk 3-4 hari, dan 15% untuk penyewaan 5 hari atau lebih).

## Fitur 

- Menyajikan daftar alat kemping beserta rincian tarif sewa harian.
- Melayani proses transaksi penyewaan secara interaktif dan akurat.
- Mencatat riwayat seluruh transaksi (hingga batas maksimal 10 transaksi) yang disajikan dalam bentuk tabel lengkap meliputi nomor, nama penyewa, jenis peralatan, jumlah unit, durasi sewa, serta total biaya.
- Menyertakan mekanisme validasi input untuk memastikan data yang dimasukkan pengguna selalu valid.
- Menu navigasi yang fleksibel dan berjalan secara terus-menerus hingga pengguna memilih keluar.

## Bahasa & Konsep yang digunakan

Aplikasi ini dibangun menggunakan bahasa pemrograman C dengan penerapan konsep modularitas fungsi, array paralel, serta struktur kontrol percabangan dan perulangan.
